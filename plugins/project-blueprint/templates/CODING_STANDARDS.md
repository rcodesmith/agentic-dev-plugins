# Coding standards

Judgement calls only: rules a reviewer applies that no linter could check. `code-review` reads this file for its Standards axis.

A rule that a tool could check (a banned API, an import shape, a naming pattern, a file location) belongs in the lint config or a CI check instead. `/retro` proposes moving such rules out of this file.
